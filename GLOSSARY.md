# Kortext Ubiquitous Language & Domain Glossary (`GLOSSARY.md`)

Canonical domain terminology for Kortext v2.0+. Agents, specifications (`to-spec`), Architecture Decision Records (`docs/adr/`), and Task DAG briefs (`to-tickets`) must use these exact terms rather than verbose paraphrases.

| Canonical Term | Definition & Architectural Invariant | Primary Module / Substrate |
|---|---|---|
| **Tier 0 Symbol Graph** | Deterministic Tree-sitter AST and SCIP compiler graph indexing declarations, signatures, line bounds, imports, and call edges in FalkorDB (`kortext_symbols`). Queried in `<2ms` via `seek_symbol` and `trace_symbol_impact`. | `kortext/symbols/` |
| **Tier 1 Hybrid Vector Store** | Dual-vector Qdrant index combining dense embeddings (`text-dense`, 384-d FastEmbed ONNX or 4096-d remote) with sparse BM25 vectors (`text-sparse-new`). | `kortext/retrieval/qdrant_engine.py` |
| **Tier 2 Bi-Temporal Episodic Graph** | FalkorDB property graph (`kortext`) storing `:Episodic` outcomes, disambiguated `:Entity` nodes, and `:RELATES_TO` edges across World Time (`valid_from`, `valid_to`) and System Time (`transaction_time`, `superseded_at`). | `kortext/episodic/driver.py` |
| **Tier 3 Architectural Overview** | Concise file skeletons (`ast_skeleton`) and Louvain community subsystem summaries (`:Subsystem`) providing macro-level repository topology. | `kortext/chunking/skeleton.py`, `kortext/symbols/clustering.py` |
| **Sole Custodian Invariant** | Only the primary `kortext.server` process (or a single active custodian when unlocked) may hold the exclusive portalocker file lock on `~/.kortext/qdrant`. Hooks and CLI scripts must never instantiate `QdrantClient(path=...)` directly while the daemon is active. | `kortext/_qdrant.py`, `FastMCPLockGuard` |
| **Anti-Ripgrep Mandate** | Prohibition against brute-force `rg`/`grep_search` sweeps over source code when locating symbol definitions or call graphs. Always use `seek_symbol` and `trace_symbol_impact`. | `kortext/hooks/pipelines/pre_tool.py` (`AntiRipgrepGate`) |
| **GateGuard First-Touch Credit** | PreToolUse blast-radius policy requiring `seek_symbol` or `trace_symbol_impact` inspection in the active turn before modifying high-in-degree ($\ge 5$ callers) or core architectural files. | `BlastRadiusGuard` |
| **Trust-Tier Execution Fence (MINJA Defense)** | Provenance state machine (`untrusted: 0.3`, `speculative: 0.5`, `tool_confirmed: 0.6`, `verified: 0.8`, `user_approved: 1.0`, `system: 1.0`). Exposure never validates: reading a memory never promotes its trust score, and only `tool_confirmed` or higher may be distilled into executable skills. | `kortext/trust/sanitizer.py`, `kortext/trust/instincts.py` |
| **MEX AST Grounding** | Binding an architectural invariant (`grounds_to`) to a symbol's normalized signature hash, AST body SHA-256 hash, and symbol-scoped token-trigram MinHash sketch to detect code drift and cross-file symbol relocation. | `kortext/invariants.py` |
| **TAA-k Knee Trimming** | Truncation-Aware Adaptive Knee trimming over 5-Signal Reciprocal Rank Fusion (RRF) scores, cutting retrieval tails at the maximum curvature drop ($k \in [3, 15]$). | `kortext/retrieval/knee_trimmer.py` |
| **Stretched Weibull Retention** | Biomimetic memory decay curve $R(t) = \max(\exp(-(t / (\lambda e^{I/10}))^\beta), 0.05)$ with half-life $\lambda = 72\text{h}$, stretching exponent $\beta = 0.65$, and a $5\%$ biological floor. | `kortext/retrieval/retention.py` |
| **Handoff Baton** | Atomic compare-and-swap JSON artifact (`~/.kortext/handoffs/<id>.json`) with a `<150`-token summary transferring context between sessions, compaction boundaries, or subagent workers without context bleed. | `kortext/handoff.py` |
| **Wayfinder Frontier** | Unblocked leaf tickets in the FalkorDB Task DAG (`get_ready`) where interfaces are known, separated from unexplored **Fog of War** zones requiring `Research`, `Grilling`, or `Prototype` tickets first. | `kortext/tasks/tracker.py`, `skills/to-tickets/` |
| **25% Compaction Ceiling** | Effective attention-degradation and auto-compaction boundary (~200k–250k tokens on 1M-window models; ~75% on 200k models) triggering Stage-1 (60% budget) advisories and Stage-2 (80% budget) automatic handoff checkpointing. | `kortext/hooks/transcript_tokens.py` |
